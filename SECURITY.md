# Security Policy

## Project

**BoxSpace Optimiser — Fit It Right, Not Just Fit It**

Developed by **Team Agile**.

## Supported Versions

Security fixes and vulnerability reports are currently accepted for the latest version of the project.

| Version        | Supported |
| -------------- | --------- |
| Latest         | Yes       |
| Older versions | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in BoxSpace Optimiser, please report it responsibly.

When reporting a vulnerability, include:

* A clear description of the vulnerability.
* Steps to reproduce the issue.
* The potential impact.
* Relevant screenshots, logs, or proof of concept, if available.
* Any suggested mitigation, if known.

### Reporting Channel

Please use GitHub's private vulnerability reporting feature if it is enabled for this repository.

Alternatively, contact the project maintainers through an official communication channel associated with Team Agile.

**Please do not disclose exploitable vulnerabilities publicly before the maintainers have had a reasonable opportunity to investigate and address them.**

## Scope

Security reports may cover:

* Cross-site scripting (XSS).
* Injection vulnerabilities.
* Insecure handling of user input.
* Exposure of sensitive information or credentials.
* Insecure API communication.
* Dependency vulnerabilities.
* Unauthorized access to application functionality.

## Responsible Disclosure

Team Agile will review submitted reports, assess their severity, and determine appropriate remediation.

Please do not access, modify, or delete other users' data, disrupt services, or perform testing beyond what is necessary to demonstrate a vulnerability.

## Security Disclaimer

This policy does not guarantee a particular response time or that every reported issue will result in a security update.

Thank you for helping improve the security of BoxSpace Optimiser.

**Maintained by Team Agile.**
